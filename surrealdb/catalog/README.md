# surrealdb-catalog

The SurrealDB catalog: schema definitions in their stored (canonical text) and
runtime (compiled AST) forms, and the provider traits the datastore layer
implements to serve them.

**This crate is an internal implementation detail of SurrealDB.** Its API is
unstable and changes without notice; depend on the `surrealdb` SDK or
`surrealdb-core` instead.
